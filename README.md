# esp32-water-level-monitor
Design and Development of a Cloud-Integrated IoT System for Early Warning and Prevention of Underpass Flood Hazards in Metropolitan cities
Main Features:
ESP32-based real-time water level monitoring
HC-SR04 ultrasonic sensor for distance measurement
Sensor mounting height: 125 cm
Alarm activates at 25 cm of water level
LED and buzzer alert system
16x2 I2C LCD display for live readings
WiFi connectivity
ThingSpeak cloud integration for remote monitoring
Data upload interval: 20 seconds
